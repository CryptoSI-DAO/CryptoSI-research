## Evaluation Criteria for Subnets

When evaluating subnets, consider:

1. **Emission share** — What % of daily TAO issuance does the subnet receive?
2. **Miner diversity** — How many unique miners? Is it concentrated?
3. **Validator quality** — Who's validating? Legitimate stakeholders or mercenary capital?
4. **Product-market fit** — Does the subnet produce something useful? Is there demand?
5. **Tokenomics** — Alpha token? Swap mechanisms? Value accrual to TAO?
6. **Team** — Builders behind the subnet, track record
7. **Roadmap** — Upcoming features, milestones
8. **Risk** — Regulatory exposure, technical risk, competition
