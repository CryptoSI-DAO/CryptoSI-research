# Ecosystem Scaffold Template

> Copy this structure when adding a new ecosystem research folder.
> Create a new folder at the repo root and populate these files.

## Folder Structure

```
ecosystem-name/
├── README.md           # Index + status tracker
├── overview.md         # Ecosystem deep dive
├── opportunities.md   # Tracked opportunities
└── notes.md           # Raw research notes
```

## README.md Template

```markdown
# [Ecosystem Name]

> Research folder for [brief description].

## Quick Links

- **Website:** [url]
- **Explorer:** [url]
- **Docs:** [url]
- **Token:** [TICKER]

## Contents

| File | Purpose |
|------|---------|
| [overview.md](./overview.md) | Ecosystem summary, tokenomics, architecture |
| [opportunities.md](./opportunities.md) | Active and potential investment opportunities |
| [notes.md](./notes.md) | Raw research notes, links, findings |

## Key Metrics to Track

- <!-- metric 1 -->
- <!-- metric 2 -->
- <!-- metric 3 -->

## Status

- [ ] Overview written
- [ ] Top projects researched
- [ ] Opportunities identified
- [ ] Cron monitoring configured
```
